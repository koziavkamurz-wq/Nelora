# Nelora

Готовые DEB и источник для Sileo. Все пакеты публикуются после компиляции.

- [Camera](Camera) — приложение камеры, удержание горизонта, белый / жёлтый экранный свет.
- [Utility](Utility) — Dock с пятью местами для приложений и отдельными настройками.
- [iOS26](iOS26) — Motion Blur и Glass, включая фон настоящей строки времени и батареи.
- [Icons](Icons) — иконки пакетов в общей теме.
- [Wallpapers](Wallpapers) — папка для обоев; пока без изображений.

Адрес источника: https://koziavkamurz-wq.github.io/Nelora/

Это адрес источника для Sileo, не веб-сайт. Публикуются Release, индексы Packages, DEB и значок источника; HTML-страницы не генерируются.

Открытые исходники и основная сборка: https://github.com/NuloraOS/TheIpOS

В зеркало попадают только опубликованные DEB, проверенные по размеру и SHA-256, и соответствующие индексы. Синхронизация запускается вручную и раз в час; GitHub может задерживать запланированные сборки. Личные данные и ключи сюда не передаются.

Цель сборок: iPhone 5s / iOS 12 / Chimera. Работа на телефоне требует проверки. Жёлтый свет создаётся экраном, а не отдельным управлением жёлтым светодиодом True Tone. Glass — оформление совместимых элементов UIKit, не перенос всей новой iOS. Motion не повышает частоту экрана. Настройки твиков — в «Настройках» iOS; после первой установки нужен ручной респринг.
