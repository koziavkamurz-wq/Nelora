# Nulora — запасной источник Sileo

https://koziavkamurz-wq.github.io/TheIpOS/

Это адрес источника для Sileo, не веб-сайт. Публикуются Release, индексы Packages, DEB и значок источника; HTML-страницы не генерируются.

Открытые исходники и основная сборка: https://github.com/NuloraOS/TheIpOS

В зеркало попадают только опубликованные DEB, проверенные по размеру и SHA-256, и соответствующие индексы. Синхронизация запускается вручную и раз в час; GitHub может задерживать запланированные сборки. Личные данные и ключи сюда не передаются.
